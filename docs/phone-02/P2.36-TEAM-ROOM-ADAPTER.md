# P2.36 — SupervisorTeamRoomAdapter seam

This is a local interface contract only. It intentionally has no HTTP implementation and no credential fields.

Required methods:
- authenticate(workloadAssertion) → authenticated local adapter session
- attach(phoneInstallationBinding) → endpoint attachment
- heartbeat(attachmentId)
- reconnect(attachmentId, freshChallenge)
- detach(attachmentId)
- send(targetPhoneId, envelope, idempotencyKey)
- receive(limit)
- ack(messageId)
- revoke(attachmentId)

P2.36 fake implementation must be deterministic, in-memory, and incapable of opening sockets. The future HTTP adapter must be owned by the Supervisor service and must not expose bearer tokens or endpoint credentials to the AppContainer. OIDC workload assertion, Team Room session bearer, endpoint credential and operator key are four separate credential classes.

No real Team Room URL, token, credential or identity is present in this mission.
